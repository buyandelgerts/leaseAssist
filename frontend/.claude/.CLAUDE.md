## Feature Component Rules

- Every feature component folder under ./src contains exactly two files: `ComponentName.tsx` and `useComponentName.ts`.
- All `useState`, `useEffect`, `useCallback`, `useMemo` live in the hook — never directly in the component file.
- Components are purely presentational — they only call their hook and render JSX.
- Split a component when it serves multiple distinct functions, has excessive nested HTML, or causes unnecessary re-renders.
